# Прокси API

Настройте подключение к backend endpoint.

1. Endpoints

Новый endpoint добавляется кнопкой (+), существующий настраивается кнопкой *settings*.

2. Load Balancing

Выберите один из 4 способов балансировки, чтобы распределять вызовы API.

3. Fail over

Настройте перенаправление вызовов, если часть endpoints недоступна.

4. CORS

Конфигурация CORS для подключений из frontend-приложений.

5. Deployment

Выберите зарегистрированные sharding tags, чтобы указать, на каком gateway должен быть развёрнут API. Sharding tags настраиваются на уровне Gateway.
Пользователь должен входить в группу, которой разрешено развёртывание на этот тег.

6. Multi-tenant

Включите режим multi-tenant, чтобы входящие вызовы шли на endpoint соответствующего tenant. Tenants настраиваются на уровне Gateway.

7. Logging

Включите журналирование, чтобы упростить отладку. Журналы доступны в разделе API Logs.
