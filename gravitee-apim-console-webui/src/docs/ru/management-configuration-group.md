# Группа

Группа — это набор пользователей API или приложения.
У каждого участника группы есть роли для действий с API или приложением.

Пользователи берутся из поставщиков удостоверений, настроенных на уровне Management API.

* флажок `Group Admin` передаёт пользователю администрирование группы,
* `API Role` — роль по умолчанию для каждого API, связанного с группой,
* `Application Role` — роль по умолчанию для каждого приложения, связанного с группой.

Кнопка (+) добавляет пользователей в группу.
