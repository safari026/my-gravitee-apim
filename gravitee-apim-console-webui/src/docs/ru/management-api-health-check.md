# Health Check API

Мониторинг состояния отправляет запросы на endpoint `health` API.
Backend API должен выполнить нужные проверки с помощью probes и вернуть признак своего состояния.

Доступность по endpoint и по gateway позволяет точно проверять состояние инфраструктуры.

Кнопка *settings* открывает настройку сервиса health check.
