# Мастер плана API

Мастер позволяет задать план, его безопасность и политики (quota, rate limit и другие).

Для планов доступны 4 типа:

* OAuth2

Тип OAuth2 проверяет access token и определяет приложение по его client ID.

* JWT

Тип JWT проверяет, что переданный JSON Web Token действителен и не истёк.

* API Key

Тип API Key определяет ключ и проверяет, что он действителен и не истёк.

* Keyless

Ничего не требуется: публичный доступ.
