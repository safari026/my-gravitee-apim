# Общие сведения API

Задайте общие сведения об API: имя, версию, изображение и описание.
Видимость API можно переключить, чтобы ограничить доступ.

В разделе портала можно добавить метки и категории, чтобы потребителям было проще найти API.

Кнопка *IMPORT* загружает определение API и заменяет текущие данные.

Кнопка *EXPORT* выгружает API в формате JSON definition, чтобы, например, воссоздать его в другом окружении.
