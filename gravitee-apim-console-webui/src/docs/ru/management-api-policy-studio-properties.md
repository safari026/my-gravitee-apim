## Свойства

Как издатель API вы можете задавать свойства API. Они автоматически попадают в контекст expression language и доступны дальше.

Например, так читается значение свойства `my-property` из свойств API:
* V2 APIs: `{#properties['my-property']}`
* V4 APIs: `{#api.properties['my-property']}`

Кнопка (+) создаёт новое свойство.

### Динамические свойства

Динамические свойства открываются кнопкой _settings_. Они позволяют получать свойства API из удалённого ресурса, например из веб-сервиса.

Можно задать частоту опроса и преобразование ответа с помощью [JOLT framework](http://bazaarvoice.github.io/jolt/).

Не забудьте включить динамические свойства и заново развернуть API. Как и обычные свойства, динамические попадают в контекст expression language.
