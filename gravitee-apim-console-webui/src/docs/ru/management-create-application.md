# Создание приложения

Приложение нужно, чтобы подписаться на план API. Это промежуточное звено между пользователем (вами) и API,
которым управляет кто-то другой.


Приложение — простая сущность из небольшого набора свойств, которые в основном описывают приложение
и то, что оно делает.

При необходимости укажите домен приложения (например, `https://my-app.com`). Это поможет издателям API правильно настроить контроль доступа.
Подсказка: можно указать несколько доменов через запятую.
