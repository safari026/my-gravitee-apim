# Общие сведения приложения

Задайте общие сведения о приложении: имя, тип (mobile/web) и описание.
Приложению также можно дать доступ для зарегистрированных групп.

При необходимости укажите домен приложения (например, `https://my-app.com`). Это поможет издателям API правильно настроить контроль доступа.
Подсказка: можно указать несколько доменов через запятую.
