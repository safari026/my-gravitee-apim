# Настройка темы

Здесь задаётся тема, и сразу виден предварительный просмотр.

**Панель слева** от просмотра задаёт параметры оформления.

Кнопка **FULLSCREEN** удобна, если экранов несколько: просмотр открывается в новом окне.
`Только если в настройках портала указан Portal URL.`

Действие **RESET** возвращает тему к состоянию после последнего сохранения.

Кнопка **SAVE** сохраняет тему.

Переключатель **ENABLED** делает тему активной на уровне портала.

Действие **RESTORE TO DEFAULT THEME** заменяет ваши изменения темой, которая поставляется по умолчанию.

#### Простое использование

**Images** Добавьте логотипы. Необязательный логотип используется на домашней странице и в подвале, но можно оставить только основной логотип по ссылке
"Use default logo".
Добавьте фоновое изображение домашней страницы.

**Colors** Задайте основной, нейтральный, цвет шрифта и цвет skeleton.

**Fonts** Выберите семейство шрифта. Выберите размер шрифта. По умолчанию используется Small.

#### Расширенное использование

Если нужна более тонкая настройка, можно задать графические свойства, которые открыты для каждого компонента.

У каждого компонента свои свойства, но где это возможно, они собраны в общие переменные (см. простое использование).

Для цветов компонента наведение на цветовой кружок показывает, какой общий цвет используется.
Для остальных свойств, если используется общее свойство, это видно в placeholder поля.
