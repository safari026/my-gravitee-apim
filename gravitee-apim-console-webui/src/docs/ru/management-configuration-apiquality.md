# Качество API

Оценка качества API считается по критериям:

- документация есть и опубликована
- настроен health-check
- описание не короче заданной длины
- не используется логотип по умолчанию
- у API заданы категории и метки

Цель — побудить издателя API заполнить необязательные поля по правилам администратора.
Процент рассчитывается по этим правилам и их весам.


## Ручные правила качества

Рецензент может проверять качество API по правилам, заданным вручную.
У этих правил есть вес, который учитывается в итоговой оценке.
