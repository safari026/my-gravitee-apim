# Аудит

Здесь собраны все изменения, которые создаёт API Management.
Их также можно фильтровать.

Описание записи аудита:

* **Date**: когда создана запись аудита
* **User**: пользователь, который создал запись
* **Type**: тип родительской сущности записи (API/APPLICATION/PORTAL)
* **Reference**: имя родительской сущности (имя API или приложения)
* **Event**: тип события
* **Target**: объект изменения
* **Patch**: JSON Patch изменения
