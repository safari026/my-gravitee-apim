# Регистрация клиентов

Поставщики регистрации клиентов позволяют подключить любой сервер авторизации, совместимый с [OpenID Connect Dynamic Client Registration](https://openid.net/specs/openid-connect-registration-1_0.html).

Такой поставщик DCR (Dynamic Client Registration) автоматически связывает OAuth-клиент
с приложением и применяет практики безопасности в соответствии с выбранным типом приложения.
