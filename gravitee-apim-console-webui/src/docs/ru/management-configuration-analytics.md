# Аналитика

## Настройки

Здесь настраиваются параметры аналитики.

## Панели

Здесь выбираются панели, которые нужно показывать.

Панели можно отдельно настроить для API, приложений и платформы.

Панели можно добавлять, удалять, изменять и менять порядок, включать и выключать, а также настраивать виджеты на каждой из них.
