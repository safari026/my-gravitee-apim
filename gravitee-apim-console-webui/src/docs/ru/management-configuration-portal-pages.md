# Страницы портала

Сейчас поддерживаются четыре типа документов:

* Swagger/OpenApi.
* Markdown (MD).
* AsciiDoc.
* AsyncApi.

По умолчанию страницы портала находятся в режиме staging и видны администраторам и пользователям с ролями управления порталом.

Чтобы документация была видна всем пользователям, включите кнопку *published*.
Страницы портала открываются из основного раздела *DOCUMENTATION*.

*homepage* задаётся кнопкой *house*. Домашняя страница портала видна на входной странице портала.

Страницу также можно настроить кнопкой *settings*. Настройка позволяет брать содержимое из внешнего ресурса, например из Git-репозитория или по HTTP URL.

Новая страница документации создаётся кнопкой (+).

Можно добавить целый каталог. Нажмите ссылку вверху экрана, чтобы импортировать каталог.
Если в каталоге есть дескриптор Gravitee (файл `.gravitee.json`), содержимое будет добавлено по этому дескриптору.

Пример дескриптора:
```json
{
  "version": 1,
  "documentation": {
    "pages": [
      {
        "src": "/docs/readme.md",
        "dest": "/my/new/dir/",
        "name": "Homepage",
        "homepage": true
      },
      {
        "src": "/docs/doc2.md",
        "dest": "/my/new/dir/",
        "name": "Business"
      }
    ]
  }
}
```
