# Шаблон ответа


## Обзор
Шаблон ответа задаётся по заголовку запроса `Accept`.
Можно описать столько content-type, сколько нужно для разных тел ответа, например `application/json` или `text/xml`.

Если ни один шаблон не подходит к заголовку `Accept`, можно задать
запасной ответ с типом `*/*`.

Если запасной шаблон не задан, потребителю API уйдёт обычный ответ политики.

## Конфигурация
Для каждого типа нужно настроить ответ:
* A status code
* HTTP headers
* A body

Шаблон тела ответа поддерживает Expression Language, поэтому в сообщение можно подставить нужные значения.


## Примеры

Для API-KEY:

```json
{
  "message": "{#error.message}",
  "api-key": "{#parameters['api-key']}"
}
```

В этом примере `#error.message` — обычное сообщение, которое отправляет политика.
