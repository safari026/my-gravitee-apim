# Оповещения

Здесь собрана общая информация и основные показатели оповещений платформы.

Первый график показывает число событий по уровню важности оповещения.

Вторая строка даёт краткий обзор оповещений: сначала по уровню важности, затем по убыванию числа событий за выбранный интервал. Оповещение появляется только если за этот интервал произошло событие.
