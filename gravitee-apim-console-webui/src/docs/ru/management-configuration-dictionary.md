# Словарь

Словарь может быть MANUAL или DYNAMIC.

## MANUAL
Для словаря _manual_ администратор (или любой пользователь с правом обновления) сам
создаёт, изменяет и удаляет свойства.

Он же разворачивает словарь на API Gateways.


## DYNAMIC
Для словаря _dynamic_ свойства обновляются автоматически по данным провайдера.

Когда обнаруживается отличие новых свойств от предыдущих, словарь автоматически
разворачивается на API Gateways и становится доступен при обработке HTTP-запроса.
