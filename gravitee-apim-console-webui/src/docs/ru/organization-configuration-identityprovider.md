# Поставщик удостоверений

Поставщик удостоверений в основном основан на протоколах OAuth2 / OIDC.

## Конфигурация

Этот раздел настраивает доступ к серверу авторизации. В зависимости от типа поставщика
удостоверений часть расширенных параметров может быть обязательной.

## Профиль пользователя

Когда пользователь входит в Gravitee.io через внешнего поставщика удостоверений или социального провайдера, нужно получить
сведения об аутентифицированном пользователе и частично сохранить их в базе Gravitee.io.

Сопоставление профиля позволяет связать свойства пользователя в Gravitee со значением
(атрибутом или claim) из профиля user_info.

## Сопоставление групп

Сопоставление групп автоматически добавляет пользователя в группу по заданному условию (поддерживается EL).

Пример:
```
{#jsonPath(#profile, '$.identity_provider_id') == 'idp_5' && #jsonPath(#profile, '$.job_id') != 'API_BREAKER'}
```

## Сопоставление ролей

Сопоставление ролей автоматически назначает пользователю роль по заданному условию (поддерживается EL).

Пример:
```
{#jsonPath(#profile, '$.identity_provider_id') == 'idp_5' && #jsonPath(#profile, '$.job_id') != 'API_BREAKER'}
```
