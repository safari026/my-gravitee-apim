# Подписки приложения

Список зарегистрированных подписок по API. Подписка — это планы, на которые подписано приложение.

Подписки бывают такими:

* Accepted

Подписка действительна, и приложение может вызывать операции API со своим API Key.
Подписку можно продлить, отозвать, либо она действует до даты окончания.

* Pending

Приложение запросило доступ к API и ожидает подтверждения владельцев API.

* Rejected

Подписка отклонена, и приложение не может использовать API.

* Closed

Подписка закрыта, и приложение не может использовать API.
