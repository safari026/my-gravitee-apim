# Настройки портала

Будьте внимательны при изменении значений: они станут доступны в каждой новой сессии пользователя.

Например, можно выбрать тему портала или включить функции вроде Support и Rating.

Некоторые настройки доступны только для чтения, потому что заданы переменными окружения.

## Конфигурация API Key

Режим custom API Key позволяет задавать произвольные значения API Key. Так издатели API могут перейти на Gravitee.io, не меняя API Key потребителей.

Режим shared API Key заставляет потребителей использовать один и тот же API Key для всех подписок приложения на API.
Когда режим включён, при второй подписке потребителю предлагают выбрать: использовать ключ
для всех подписок или создать отдельный API Key для каждой подписки (это режим по умолчанию).

Выбор постоянный: потребитель не сможет вернуться к отдельному ключу на каждую подписку этого приложения.

Если режим shared API Key выключить, приложения, которые уже используют общий ключ, продолжат
работать так же, но при второй подписке потребителям больше не будут предлагать выбрать режим.
