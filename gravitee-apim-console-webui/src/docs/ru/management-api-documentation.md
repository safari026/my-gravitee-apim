# Документация API

Сейчас поддерживаются два типа документов:

* Swagger
* Markdown (MD)

На страницах Markdown можно обращаться к данным API (имя, версия, описание и т. д.), записывая в содержимом страницы `${api.name}` или `${api.metadata['foo-bar']}`. Документация OpenAPI обрабатывается как данные спецификации и не поддерживает эти шаблонные выражения.

По умолчанию страницы документации находятся в режиме staging и видны владельцам API и участникам с соответствующими ролями документации.
Чтобы страница была видна всем пользователям, включите кнопку *published*.

Страницу можно сделать *homepage* кнопкой *house*. Домашняя страница API видна на главной странице API в портале.

Страницу также можно настроить кнопкой *settings*. Настройка позволяет брать содержимое из внешнего ресурса, например из Git-репозитория или по HTTP URL. В этом случае можно включить автоматическое обновление (см. Auto Fetch ниже).

Кнопка (+) создаёт новую страницу документации.

Можно добавить целый каталог. Нажмите ссылку вверху экрана и импортируйте каталог.
Если в каталоге есть дескриптор Gravitee (файл `.gravitee.json`), содержимое будет добавлено по этому дескриптору.

Пример дескриптора:
```json
{
  "version": 1,
  "documentation": {
    "pages": [
      {
        "src": "/docs/readme.md",
        "dest": "/my/new/dir/",
        "name": "Homepage",
        "homepage": true
      },
      {
        "src": "/docs/doc2.md",
        "dest": "/my/new/dir/",
        "name": "Business"
      }
    ]
  }
}
```

## Auto Fetch

Чтобы периодически получать документацию из внешнего источника, включите параметр 'Auto Fetch' и укажите частоту.

Частота задаётся __cron expression__: это строка из шести полей, которые описывают секунду, минуту, час, день, месяц и день недели.

Примеры:

* Каждый час: `* * */1 * * *`
* В 00:00 в субботу: `0 0 0 * * SAT`

__Примечание__: администратор платформы мог задать максимальную частоту, которую нельзя превысить. Например, если обновление настроено каждую минуту, а администратор ограничил период 5 минутами, обновление будет выполняться каждые 5 минут.
