# Журналирование API

Здесь можно включить аудит просмотра подробностей журнала.
Это полезно, чтобы отслеживать, кто открывал конкретные данные в представлении аудита.

Для плана OAuth2/JWT можно показывать или скрывать конечного пользователя.
Он извлекается из claim `sub`.

Также можно ограничить длительность полного журналирования API (0 означает, что максимальной длительности нет).
Это не даёт издателям API слишком долго записывать заголовки и тело и снижает расход CPU и памяти.
По умолчанию вызовы записываются с минимальным набором сведений.
