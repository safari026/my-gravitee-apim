# Теги шардирования

Sharding tags позволяют ограничивать и разворачивать отдельные API на экземплярах Gateway с теми же тегами.

Новый тег создаётся в поле *New tag*, затем нажимается кнопка *SAVE*.
Идентификатор тега создаётся автоматически.

Чтобы связать API и экземпляры Gateway,
выберите этот тег на странице конфигурации API и скопируйте его идентификатор в файл `gravitee.yml` экземпляра gateway:

```yaml
# Sharding tags configuration
# tags: products,!international
```
