# Настройка оповещений

## Оповещения

Настройте собственные оповещения.

Получайте письмо, когда меняется статус health check или когда квота достигает заданного процента.

Примеры настройки есть в документации Gravitee: <a href="https://documentation.gravitee.io/apim/getting-started/configuration/configure-alerts-and-notifications#configure-notifications-for-your-apis" target="blank">уведомления</a> и <a href="https://documentation.gravitee.io/apim/getting-started/configuration/configure-alerts-and-notifications#configure-alerts" target="blank">оповещения</a>
