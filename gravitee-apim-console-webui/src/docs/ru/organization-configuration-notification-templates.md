# Шаблоны уведомлений

Здесь собраны шаблоны, которые используются, когда на платформе срабатывают уведомления, а также шаблоны писем для отдельных действий.

Шаблоны сгруппированы по категориям:
* API
* Application
* Portal
* Templates for action

В последней категории **Templates to include** находятся HTML-шаблоны, которые можно включать в другие письма (например, `header.html`).

Нажмите шаблон, чтобы изменить уведомление портала и/или письмо.

Если уведомление портала или письмо изменено, к имени шаблона добавляется метка `CUSTOM`.
