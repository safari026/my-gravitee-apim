# Создание API по шагам

Создание API проходит в 4 шага.

. General **required**

Задайте имя, версию, описание и context-path API.

. Proxy **required**

Укажите backend endpoint.

. Plan **optional**

Чтобы подписаться на API, нужно опубликовать один или несколько планов.
План даёт доступ к операциям API.

План может быть keyless (публичный доступ) или ограниченным с помощью API-Key.
Режим auto-validation показывает, нужно ли вручную подтверждать запрос подписки.

. Documentation **optional**

Импортируйте документацию, чтобы она была доступна командам приложений.
Поддерживаются четыре типа документов: Swagger/OpenApi, AsyncApi, Markdown и AsciiDoc.
