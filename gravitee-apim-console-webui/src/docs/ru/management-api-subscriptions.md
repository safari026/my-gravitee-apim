# Подписки API

Список зарегистрированных подписок по приложениям. Подписка — это планы, на которые подписался потребитель.

Подписки бывают такими:

* Accepted

Подписка действительна, и потребитель может вызывать операции API со своим API Key.
Подписку можно продлить, отозвать, либо она действует до даты окончания.

* Pending

Потребитель запросил доступ к API. Подписку можно принять или отклонить.

* Rejected

Подписка отклонена, и потребитель не может использовать API.

* Closed

Подписка закрыта, и потребитель не может использовать API.

Кнопка (+) создаёт подписку для выбранного приложения и плана.
