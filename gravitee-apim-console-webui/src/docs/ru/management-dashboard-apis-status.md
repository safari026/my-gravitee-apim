# Состояние API

Мониторинг состояния API отправляет запросы на endpoint `health` каждого API.

Backend API должен выполнить нужные проверки с помощью probes и вернуть признак своего состояния.

API без конфигурации health-check можно скрыть или показать.

Ссылка `View detail` на карточке открывает страницу health-check конкретного API.
