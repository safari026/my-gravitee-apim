## Ресурсы

Ресурсы связаны с жизненным циклом API. Они создаются при запуске API и освобождаются при его остановке.
Политики API используют ресурсы, чтобы расширить поведение API.

Доступны разные типы ресурсов:

* Cache

Хранит данные для повторного использования и позволяет не выполнять повторные вызовы.

* OAuth 2.0

Проверяет access_token через внешний сервер авторизации OAuth 2.0.

Кнопка (+) создаёт новый ресурс.
