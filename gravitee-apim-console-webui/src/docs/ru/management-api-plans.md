# Планы API

Список зарегистрированных планов. Чтобы подписаться на API, нужно опубликовать один или несколько планов. План даёт доступ к операциям API.

У плана 3 режима:

* Staging mode

В режиме staging можно менять конфигурацию и смотреть результат до того, как план станет активным.

* Published mode

План активен, и потребители могут использовать его для подписки на API.

* Closed mode

План закрыт, и потребители API больше не могут его использовать.

Кнопка (+) создаёт новый план.
