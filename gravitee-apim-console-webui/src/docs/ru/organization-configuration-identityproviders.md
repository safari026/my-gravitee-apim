# Поставщики удостоверений

Создание поставщика удостоверений позволяет пользователям входить в портал и management-ui
с внешними учётными записями GitHub, Google, сервера OpenID Connect или Gravitee.io AM.

Можно добавить столько поставщиков, сколько нужно, и настроить каждый отдельно, чтобы управлять
группами и ролями пользователей, которые приходят из этого поставщика.
